# Сопровождение профиля

Основной и единственный файл профиля — `README.md` на русском языке. Языковых ссылок и отдельных переводов нет.

- Введение, основные проекты, навыки и контакты редактируются в `README.md`.
- `projects.json` содержит русские описания и стек проектов для каталога.
- `update_readme.py` меняет только текст между маркерами `PROJECTS`, сохраняя остальные разделы.
- В каталог попадают публичные неархивные репозитории Geist-dev, кроме форков и самого профиля. Основные проекты идут первыми, остальные сортируются по имени.
- Для нового проекта используется описание и основной язык из GitHub, пока не добавлена запись в `projects.json`.
- SVG-заголовки — локальные статические файлы для светлой и тёмной тем.

Достаточно Python 3.10+, сторонние Python-зависимости не нужны.

```bash
python -m unittest discover -s tests -v
python scripts/update_readme.py --fixture tests/repos.json
```

`tests/repos.json` — снимок публичных метаданных для автономной проверки. Для получения актуального списка уберите `--fixture`. По умолчанию используется Geist-dev; необязательный `GITHUB_TOKEN` повышает лимит API. Workflow использует автоматически созданный токен GitHub, личный токен в коде не нужен.

CI проверяет pull request без прав записи. В `main` каталог обновляется по расписанию, вручную или при изменении соответствующих файлов. При ошибке API или отсутствии маркеров скрипт завершится с ошибкой и сохранит существующий текст.

Код и SVG-файлы распространяются по MIT из корня репозитория.
